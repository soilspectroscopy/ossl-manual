2  Soil spectral libraries

Several soil spectral libraries were minimally standardized to be imported into the OSSL. The following list represents the current curated datasets, but several more are planned to be added in the future.

The Open Soil Spectral Library (OSSL) integrates diverse datasets into a unified, standardized format.

NoteFilter by Category

Use the Categories sidebar on the right to filter datasets by Spectral range or Geographic extent.

We are actively expanding this collection; if you wish to contribute a library, please contact the team.
